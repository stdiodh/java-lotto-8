# java-lotto-precourse

> 간단한 로또 발매기

## 주요 기능 목록
| 기능           | 설명                                      |
|:-------------|:----------------------------------------|
| **로또 구매**    | 1000원 단위의 구입 금액을 입력받아 금액만큼 로또를 자동 발행함   |
| **당첨 번호 입력** | 1~45 범위의 당첨 번호 6개와 보너스 번호 1개를 입력 받음     |
| **당첨 통계**    | 발행된 로또와 당첨 번호를 비교하며 1등부터 5등까지 당첨 내역을 집계 |
| **수익률 계산**   | 총 당첨금과 구입 금액을 기준으로 총 수익률을 계산함           |

## 상세 구현 기능 목록
### 1. 입력
#### 1-1. 로또 구매
- [ ] "구입금액을 입력해 주세요." 안내 문구 출력
- [ ] 구입금액 입력 받기
  - [ ] (예외) 입력값이 공백인 경우
  - [ ] (예외) 입력값이 숫자가 아닌 경우

#### 1-2. 당첨 번호 입력
- [ ] "당첨 번호를 입력해 주세요." 안내 문구 출력
- [ ] 당첨 번호 입력 받기
  - [ ] (예외) 입력값이 공백인 경우
  - [ ] (예외) 입력값이 숫자가 아닌 경우
  - [ ] (예외) 입력 숫자가 1~45 사이가 아닌 경우
  - [ ] (예외) 입력값 구분자(,)가 아닌 경우
  - [ ] (예외) 입력 숫자가 6개가 아닌 경우

#### 1-3. 보너스 번호 입력
- [ ] "보너스 번호를 입력해 주세요." 안내 문구 출력
- [ ] 보너스 번호 입력 받기
  - [ ] (예외) 입력값이 공백인 경우
  - [ ] (예외) 입력값이 숫자가 아닌 경우
  - [ ] (예외) 입력 숫자가 1~45 사이가 아닌 경우
  - [ ] (예외) 입력 숫자가 당첨 번호와 중복되는 경우

### 2. 로또 생산
- [ ] 로또 구입 금액에 따라 발행된 로또의 총 개수를 출력
  - 형식 : `8개를 구매했습니다.`
- [ ] 발행된 로또(들)를 오름차순으로 정렬 후 출력
  - 형식 : 
  ```[8, 21, 23, 41, 42, 43]
  [3, 5, 11, 16, 32, 38]
  [7, 11, 16, 35, 36, 44]
  [1, 8, 11, 31, 41, 42]
  [13, 14, 16, 38, 42, 45]
  [7, 11, 30, 40, 42, 43]
  [2, 13, 22, 32, 38, 45]
  [1, 3, 5, 14, 22, 45]
  ```

### 3. 당첨 통계 계산
- [ ] 구매한 모든 로또와 당첨 번호를 비교하여 일치하는 번호 개수 계산
- [ ] 보너스 번호 일치 여부를 확인
- [ ] 일치 결과(3개, 4개, 5개, 5개 + 보너스, 6개)에 따라 당첨 내역을 집계
- [ ] 총 당첨금을 계산
- [ ] 구입 금액 대비 총 수익률 계산
  - 수익률은 소수점 둘째 자리에서 반올림

### 4. 결과 출력
- [ ] 당첨 통계 결과를 형식에 맞게 출력
  - 형식 : 
    ```
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ```
- [ ] 계산된 총 수익률을 정해진 형식에 맞게 출력
  - 형식 : `총 수익률은 62.5%입니다.`

### 5. 테스트
- [ ] 로또 구매 금액 검증
- [ ] 로또 클래스 검증
- [ ] 당첨 번호 검증
- [ ] 당첨 통계 검증
- [ ] 수익률 계산 검증

### 6. 예외 공통 처리
- [ ] `[ERROR]`로 시작하는 에러 메시지를 출력
- [ ] 예외 발생 시 프로그램이 종료되지 않고 입력을 다시 수행하도록 함

## 과제 제출 전 체크 리스트

- [ ] 터미널에서 `java --version` 실행하여 Java 버전이 21인지 확인
- [ ] 아래 명령어를 실행하여 모든 테스트가 통과하는지 확인
  - Mac/Linux 사용자 : `./gradlew clean test`
  - Windows 사용자 : `gradlew.bat clean test` or `.\gradlew.bat clean test`
- [ ] `BUILD SUCCESSFUL in 0s` 메시지를 확인
